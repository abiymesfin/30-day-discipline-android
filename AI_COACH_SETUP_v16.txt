In Supabase Edge Function Secrets, set `AI_API_KEY` to an OpenAI API key; optionally set `AI_MODEL=gpt-6-luna` and `AI_API_URL=https://api.openai.com/v1/responses`.

SUPABASE KEY VS AI API KEY
- Supabase Project URL + publishable/anon key: identify the project and let a signed-in user call Supabase. These are separate from the AI model credential.
- `AI_API_KEY`: an OpenAI API credential, stored only as a Supabase Edge Function secret. Do not put it in HTML, JavaScript, GitHub, APK, or send it in chat.
- OpenAI API usage/billing is separate from a ChatGPT subscription. Check your OpenAI API account's access and billing before testing.
- This v16 function defaults specifically to OpenAI Responses API. A Gemini or Anthropic/Claude key will NOT work with this endpoint or request format; selecting either provider requires the corresponding provider-specific server integration.

PRIVACY / SAFETY
The Edge Function verifies the Supabase user's access token and does not send Journal text. It sends only the chat message/goal and aggregate challenge statistics. It sets `store:false` for API requests. Before public launch, add per-user rate limits, budget caps/monitoring, and review your provider's data controls. The AI gives general habit/nutrition/activity advice only, not medical diagnosis or treatment.
